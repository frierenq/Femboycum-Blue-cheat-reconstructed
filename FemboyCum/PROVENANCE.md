# Provenance and release boundaries

This candidate preserves the active experimental C++ foundation's implementation, interfaces, fixtures and build graph. It does not reproduce the complete historical product, claim original product source recovery or provide a working launcher/payload bundle.

`include/fc`, `src`, `tests`, project build integration and development utilities are recorded as newly authored reconstruction work. They implement bounded contracts and independent engineering policies. A public project-wide licence has not been assigned.

`recovered/PROVENANCE.json` records 33 analyst-authored semantic projections and console fixtures, copied byte-for-byte into the active foundation. Their source hashes remain intact. Private absolute provenance pointers were removed from this candidate; the original records remain in the development workspace. No explicit subtree redistribution grant was found. This is a distinct unresolved rights issue, not permission inferred from an authorship statement.

The exponent helper implementation includes a generated numeric table dependency. The original `src/uniform_random_exp_tables.inc` was derived from an exact 1,472-byte interval in a proprietary game module. Its redistribution rights have not been established, so it is withheld. Its absence blocks a complete Core/DLL build. The authored implementation is preserved; no substitute data or behavior is supplied.

The optional LuaJIT and Detours subtrees have pinned upstream revisions, source-file manifests and retained upstream notices. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). These licences apply to their respective sources and do not establish a licence for the project or the model subtree.

The historical wrapper, launcher and Rust service are separately supplied historical components. The wrapper needs original embedded core/helper payloads; launcher licence/package metadata conflict; associated seed data, icons, fonts and other assets lack a verified per-item rights closure. Those components and their payloads are excluded pending separate provenance work. This candidate does not conceal a complete independently authored launcher implementation.

Original core/game/OS images, compiled dependencies, decompiler/disassembly output, protected loaders, raw VM captures, machine identifiers, private filesystem records and unrelated research are excluded. Selected authored contracts and portable utilities may refer to evidence hashes or address identifiers; those references are not bundled binaries, executable permissions or compatibility guarantees.

The complete private omission and transformation report is stored outside this candidate. Original development inputs are preserved. No remote repository, upload, rewritten history or public release is part of this preparation.
